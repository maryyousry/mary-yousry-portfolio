## 🚀 How to Run & Preview

This website is completely self-contained with no build steps or heavy dependencies required.

### Option 1: Open Directly in Any Browser
Double-click `index.html` or open it with your favorite browser:
```bash
# In Windows PowerShell:
Start-Process "C:\Users\maryy\.gemini\antigravity\scratch\mary-yousry-portfolio\index.html"
```

### Option 2: Run with Local HTTP Server
```bash
# Using Python:
cd C:\Users\maryy\.gemini\antigravity\scratch\mary-yousry-portfolio
python -m http.server 3000

# Open http://localhost:3000 in your browser
```
